# nniklab_projects

Repositorio central de los proyectos de nniklab. Cada trabajo vive en su propia carpeta.

## Estructura

```
nniklab_projects/
├── README.md      ← este archivo: índice de proyectos
├── CONTEXTO.md    ← estado general y cómo retomar el trabajo
└── <proyecto>/    ← una carpeta por proyecto
    ├── README.md  ← qué es el proyecto y cómo usarlo
    └── NOTAS.md   ← decisiones, estado y próximos pasos
```
