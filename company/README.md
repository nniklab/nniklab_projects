# company

Construcción de la marca de la empresa y de los servicios que ofrece.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `01-marca/logo/` | Bocetos, versiones del logo y archivos finales (SVG, PNG) |
| `01-marca/colores/` | Paleta de colores con códigos HEX/RGB/CMYK |
| `01-marca/tipografia/` | Fuentes elegidas y cómo usarlas |
| `02-servicios/` | Catálogo de servicios, fuentes de datos y tecnologías |
| `03-comunicacion/` | Identidad verbal, slogan, perfil del fundador y textos clave |
| `04-materiales/` | Tarjetas, presentaciones, plantillas para redes sociales |
| `05-web/` | Sitio web de una sola página: estructura (`estructura.md`) y recursos propios (logos de tecnologías) |
| `06-publicidad/` | Videos, audio e imágenes (gráficos y fondos, también usados en la web) |
| `99-respaldo/` | Propuestas descartadas o guardadas para el futuro (no en uso) |

El orden numérico refleja el orden de trabajo: primero la identidad visual, luego el resto se construye sobre ella.
