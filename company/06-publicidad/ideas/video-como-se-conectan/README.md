# Video "Cómo se conectan"

Idea para un video publicitario propio, basado en la sección "Cómo se conectan" que estuvo en el sitio web hasta la v1.1.

## Estado

**Pendiente.** Todavía no hay guion ni video. Esta carpeta guarda el contexto para hacerlo más adelante.

## Por qué existe esta carpeta

El 2026-10-19 se quitó la sección del sitio (v1.2) porque ocupaba mucho espacio, sobre todo en el celular. El mensaje es la propuesta diferencial de nniklab, así que no se descarta: se reserva para un video exclusivo.

## El mensaje

- **Idea central:** las tres líneas de servicio forman un solo sistema. Los datos alimentan las automatizaciones y los agentes de IA trabajan sobre ambos.
- **Diferenciador:** "Eso nos diferencia de quien solo hace dashboards o solo automatiza."
- **Título usado en la web:** "De tus fuentes de datos a **decisiones**, en un solo flujo." ("decisiones" resaltado en lima).

## Contenido de la sección (texto tal como estaba)

Etiqueta: `/cómo_se_conectan`. Diagrama de izquierda a derecha.

**Entradas (fuentes de datos del cliente)**

- Sistemas de gestión · ERP, contabilidad, CRM
- Facturación electrónica · XML del SRI
- Archivos y documentos · Excel, PDF
- Bases de datos
- Canales · correo, WhatsApp, formularios
- Ventas en línea y marketing

**Centro: nniklab `// sistema`**, tres bloques conectados en orden:

1. **Datos** (01): Microsoft Fabric, Data Factory, Power BI.
2. **Automatización** (02): n8n, Power Automate.
3. **IA** (03, bloque en lima): Azure OpenAI, Claude.

**Resultados**

- Dashboards: para decidir con datos confiables.
- Procesos automáticos: que corren solos, sin digitar.
- Agentes de IA: que responden y actúan.

En la web, unos pulsos lima viajaban por las flechas y por los conectores entre Datos, Automatización e IA. Esa idea de "datos que fluyen" es la base natural para animar el video.

## Ideas para el video

- Recorrido en tres tiempos: las fuentes desordenadas entran → pasan por Datos, Automatización e IA → salen como resultados.
- Formato vertical 9:16, como el intro v3, para redes. Se puede sacar también una versión horizontal para la web.
- Cerrar con el diferenciador y el slogan oficial.
