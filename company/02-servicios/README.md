# Servicios

Catálogo de servicios de nniklab. Definido el 2026-10-17.

nniklab ofrece tres líneas de servicio que funcionan por separado o como un solo sistema: **los datos alimentan las automatizaciones y los agentes de IA trabajan sobre ambos.**

## 1. Datos

Tratamiento de datos: ingeniería, análisis y arquitectura.

- **Arquitectura de datos:** diseño de la estructura y el flujo de la información del negocio.
- **Ingeniería de datos:** construcción de ETL y procesos que integran, limpian y mueven los datos de forma confiable.
- **Análisis de datos:** indicadores, modelos y hallazgos para entender el negocio.
- **Dashboards:** tableros para la toma de decisiones.

**Resultado:** información centralizada, confiable y visible para decidir.

## 2. Automatización de procesos

- Diseño de automatizaciones que eliminan procesos manuales y generan resultados.
- Integración de aplicaciones para que los sistemas se hablen entre sí.

**Resultado:** menos trabajo manual, menos errores y resultados que se generan solos.

## 3. Inteligencia artificial

- Agentes de IA para el manejo de la información.
- Agentes que trabajan dentro de los procesos de automatización: leen documentos, responden consultas y toman decisiones simples.

**Resultado:** procesos que van más allá de las reglas fijas.

## Tecnologías

- **Datos y nube:** Azure · Azure Databricks · Azure SQL · Data Factory · Microsoft Fabric · Power BI
- **Bases de datos:** Oracle · SQL Server · PostgreSQL
- **Automatización:** n8n · Power Automate · SharePoint · Microsoft 365
- **IA:** Azure OpenAI · API de OpenAI · API de Claude (Anthropic)
- **Desarrollo e integración:** Python · APIs REST · Git / GitHub
